# Яндекс.Маркет — basics

Last Updated: 2026-05-29
Источник: [Я.Маркет Partner API](https://yandex.ru/dev/market/partner-api/)

## Модели работы

| Модель | Описание | Когда выбирать |
|--------|----------|----------------|
| **FBY** (Fulfillment By Yandex) | Товар на складе Я.Маркета | Большие объёмы |
| **FBS** | Товар у селлера, ЯМ забирает курьером | Средний оборот |
| **Express** | Доставка за 1-2 часа в городе | Локальный premium |
| **DBS** (Delivery By Seller) | Селлер сам доставляет | Габаритные товары |

## Базовые тарифы (2026, ориентировочно)

- **Комиссия:** 0-19% по категории (есть категории с 0% комиссией для новых селлеров!)
- **Логистика FBY:** ~40-80 руб/единица
- **Хранение FBY:** 0.4-1.5 руб/единица/день
- **Эквайринг:** ~1.5%
- **Возвраты:** ~50-80 руб/возврат

⚠️ Проверяй актуальные тарифы → market.yandex.ru/partner.

## API

### Базовые группы

| Группа | Назначение | URL |
|--------|------------|-----|
| **Partner API** | Каталог, заказы, цены, кампании | `api.partner.market.yandex.ru` |
| **Stat API** | Статистика | `api.partner.market.yandex.ru/stats` |

### Аутентификация

OAuth 2.0:

```http
GET /campaigns/{campaignId}/offers.json HTTP/1.1
Host: api.partner.market.yandex.ru
Authorization: OAuth y0_AgAAA...
```

OAuth-токен получается через Я.OAuth-приложение (oauth.yandex.ru).

### Rate limits

- Partner API: **до 100 RPS** на бизнес-аккаунт
- Stat API: более жёсткие лимиты, пагинация по `pageToken`

## Особенности

- **Карточка товара:** до 10 фото + видео + видео-обзоры
- **Маркировка ЧЗ:** обязательна
- **Сертификация:** требования ниже, чем у WB/Ozon в некоторых категориях
- **Возвраты:** ~20-35% (зависит от категории)
- **Программа лояльности:** Я.Плюс даёт кешбэк покупателю → влияет на конверсию

## Best practices (FREE basics)

1. **Используй параметры каталога** — Я.Маркет ранжирует по детализации
2. **Я.Реклама** — реклама внутри Я.Маркета через рекламный кабинет
3. **Цены:** Я.Маркет агрегирует цены — будь конкурентноспособен в первые 3 позиции
4. **Express в крупных городах** — даёт +30-50% конверсии для повседневных товаров
