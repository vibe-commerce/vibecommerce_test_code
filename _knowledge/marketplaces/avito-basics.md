# Avito — basics

Last Updated: 2026-05-29
Источник: [Avito.ru](https://www.avito.ru/) / [Avito Doставка](https://www.avito.ru/avito-delivery)

## Модели работы

| Модель | Описание | Когда выбирать |
|--------|----------|----------------|
| **Классифайд** | Авито = доска объявлений, ты сам общаешься с покупателем | C2C, ниши без выкупа Avito |
| **Avito Доставка** | Авито выкупает товар у тебя, отправляет покупателю | B2C, FMCG, базовый ассортимент |
| **Avito для бизнеса** | Premium-аккаунт + продвижение | Большой объём, бренд |

## Базовые тарифы (2026, ориентировочно)

Avito — модель с **оплатой за продвижение**, не за продажу:

- **Пакеты услуг** — продвижение объявлений (XL, Premium, VIP)
- **Авито Доставка комиссия:** 4-15% от продажи
- **Стоимость размещения** для бизнес-аккаунтов — фиксированная за слот категории
- **Тарифы Avito Pro** — от ~3000 руб/месяц за рабочий аккаунт

⚠️ Авито не подходит для всех ниш — лучше работает с FMCG, мебелью, одеждой, электроникой.

## API

Avito API **закрытый** для большинства селлеров. Доступ через:
- **Avito Pro** — личный кабинет с массовым управлением (CSV-импорт, не API)
- **Партнёрские интеграции** через 1С/МойСклад/RetailCRM (через Avito Pro)

## Особенности

- **Карточка товара:** 10 фото + видео + интерактивный диалог
- **Сертификация:** требуется для определённых категорий (тех. товары, БАДы)
- **Возвраты:** через Авито Доставку — стандартная процедура
- **Аудитория:** более ценочувствительная, чем WB/Ozon

## Best practices (FREE basics)

1. **Описание с триггерами доверия** — гарантия, опыт, фотоотзывы
2. **Премиум-продвижение** окупается на дорогих товарах (> 5000 руб)
3. **Быстрые ответы в чате** — рейтинг Avito и видимость зависят от response time
4. **Категория и подкатегория** правильные — это определяет показы
