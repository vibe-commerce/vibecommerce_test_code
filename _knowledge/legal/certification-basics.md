# Сертификация и декларирование — basics

Last Updated: 2026-05-29
Источники: [ПП РФ № 2425](https://base.garant.ru/12191967/), [Росаккредитация](https://fsa.gov.ru/)

## Что регулирует

Порядок подтверждения соответствия товаров требованиям технических регламентов
(ТР ТС / ТР ЕАЭС) и национальных стандартов. Основной документ — **ПП РФ № 2425**
«Об утверждении единого перечня продукции, подлежащей обязательному
подтверждению соответствия».

## Виды подтверждения соответствия

| Тип | Кто оформляет | Срок | Когда нужен |
|-----|---------------|------|-------------|
| **Сертификат соответствия (СС)** | Аккредитованный орган | 1-5 лет | Высокий риск (электроника, СИЗ, дет. товары) |
| **Декларация о соответствии (ДС)** | Заявитель (ИП/ООО) с протоколом испытаний | 1-5 лет | Средний риск (одежда, обувь, мебель) |
| **Свидетельство о госрегистрации (СГР)** | Роспотребнадзор | бессрочно | Косметика, БАДы, дет. питание |
| **Отказное письмо** | Аккредитованный орган | бессрочно | Подтверждение, что товар НЕ требует серт. |

## Алгоритм классификации (FREE basics)

```
1. Определить ТН ВЭД код товара (или ОКПД2)
   ↓
2. Найти в перечне ПП РФ № 2425 — есть/нет?
   ↓
3a. ЕСТЬ → определить тип: СС/ДС/СГР по колонке
   ↓
3b. НЕТ → требуется отказное письмо (на запрос МП)
```

Используй скрипты в `_modules/06-certification-legal/scripts/`:

```bash
python _modules/06-certification-legal/scripts/classify_by_legislation.py my-skus.csv
```

## Где получать документы

### Сертификат соответствия (СС)
- Только в аккредитованной лаборатории / органе сертификации
- Стоимость: 15-80 тыс. руб (зависит от ТР и партии)
- Список органов: [fsa.gov.ru/use-of-information/reestry/](https://fsa.gov.ru/use-of-information/reestry/)

### Декларация о соответствии (ДС)
- Проходишь испытания в аккредитованной лаборатории
- Получаешь протокол испытаний
- Регистрируешь декларацию в [Едином реестре](https://pub.fsa.gov.ru/rds)
- Стоимость: 10-40 тыс. руб

### СГР
- Через Роспотребнадзор → отдел санэпиднадзора региона
- Срок: 30-60 рабочих дней
- Стоимость: 2-15 тыс. руб (без испытаний)

### Отказное письмо
- Через любой аккредитованный орган
- Стоимость: 2-5 тыс. руб
- Бессрочное

## Требования маркетплейсов

### Wildberries
- Запрашивает СС/ДС/СГР для категорий с требованием
- Отказное письмо — для категорий, которые ВЫГЛЯДЯТ как требующие, но не требуют
- Проверка через `_modules/06-certification-legal/scripts/check_wb_requirements.py`

### Ozon
- Аналогичная схема + дополнительные требования по составу для FMCG
- Проверка через `_modules/06-certification-legal/scripts/check_ozon_requirements.py`

### Я.Маркет
- Похожие требования, в некоторых категориях более жёсткие

## Штрафы за отсутствие документов

| Нарушение | Штраф для ИП |
|-----------|---------------|
| Продажа без обязательной сертификации | 20000-30000 ₽ + конфискация |
| Поддельный сертификат | 30000-50000 ₽ + уголовка (если ущерб) |
| Несоответствие товара заявленному | 20000-30000 ₽ |

## Чек-лист «готов запускать товар»

- [ ] ТН ВЭД / ОКПД2 код определён
- [ ] Проверено по ПП РФ № 2425 — нужна ли сертификация
- [ ] Если нужна — выбран орган/лаборатория, оплачено
- [ ] Получены документы (СС/ДС/СГР/Отказное)
- [ ] Документы загружены в карточку МП
- [ ] У себя — оригиналы документов (на проверку Роспотребнадзор)
