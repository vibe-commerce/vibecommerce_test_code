## Что нужно сделать селлеру

### 1. Регистрация в ЧЗ
- Через [личный кабинет ЧЗ](https://честныйзнак.рф/business/projects/)
- УКЭП (усиленная квалифицированная электронная подпись) — обязательна
- Для ИП — УКЭП на физлицо-ИП

### 2. Регистрация в ЭДО
- ЭДО (электронный документооборот) — обязателен для отправки данных в ЧЗ
- Платформы: СБИС, Контур, Такском, 1С-ЭДО, и др.

### 3. Получение Data Matrix кодов
- Покупка кодов в ЛК ЧЗ (50 копеек/код, оптовые скидки)
- Нанесение на товар: типография, термопечать, или через производителя

### 4. Передача данных
- При продаже — пробить чек 54-ФЗ с кодом
- При движении товара — УПД через ЭДО

## Особенности для МП-селлеров

- ⚠️ **WB/Ozon/ЯМ автоматически передают данные** при FBO-схеме
- При FBS-схеме селлер сам ответственен за корректную передачу кода в ЧЗ
- При **возвратах** — код выводится из оборота через ЧЗ
- **Контроль перевозок** — каждое движение подкатегорий обуви/одежды отслеживается

## Штрафы

| Нарушение | Штраф для ИП |
|-----------|---------------|
| Отсутствие маркировки на товаре | 10000 ₽ + конфискация |
| Продажа товара без передачи кода в ЧЗ | 10000 ₽ + конфискация |
| Производство без маркировки | 5000-10000 ₽ + конфискация |
| Юрлицам — выше: до 300000 ₽ + конфискация |

## Чек-лист «готов работать с маркировкой»

- [ ] Категории товаров проверены на наличие в списке маркировки
- [ ] Получена УКЭП (для ИП — на физлицо)
- [ ] Регистрация в ЛК ЧЗ
- [ ] Подключение к ЭДО (СБИС/Контур/Такском)
- [ ] Закуплены коды Data Matrix
- [ ] Нанесение кода на товар (или заказана партия с маркировкой у производителя)
- [ ] Тестовая продажа с передачей кода в ЧЗ
