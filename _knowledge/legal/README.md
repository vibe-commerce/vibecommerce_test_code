## Самое важное (для быстрого старта)

### Для запуска селлерства как ИП
- УСН 6% от оборота — простейший вариант для большинства селлеров < 60 млн оборота/год
- УСН 15% (доходы-расходы) — если расходы > 60% оборота (закупка + реклама)
- Касса 54-ФЗ — для DTC обязательна, для МП — МП сам выдаёт чеки

### Для карточки товара
- Сертификация → проверь через `_modules/06-certification-legal/scripts/`
- Маркировка ЧЗ → для одежды/обуви/парфюма обязательна
- Описание товара — без обмана / преувеличений (иначе риск штрафа ФАС)

### Для лендинга / оферты
- Оферта B2C — должна соответствовать ЗоЗПП
- Согласие на ПДн — обязательно по 152-ФЗ
- Политика конфиденциальности — обязательна
