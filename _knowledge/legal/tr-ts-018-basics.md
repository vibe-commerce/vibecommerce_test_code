# ТР ТС 018/2011 — basics

Last Updated: 2026-05-29
Источник: [ТР ТС 018/2011 — Гарант](https://base.garant.ru/12191989/)

## Что регулирует

**Технический регламент Таможенного союза «О безопасности колёсных
транспортных средств»** — требования к безопасности легковых, грузовых,
прицепов и **компонентов** (в т.ч. автозапчастей).

## Когда применять (для селлера)

ТР ТС 018/2011 распространяется на:

1. **Колёсные транспортные средства** (целиком)
2. **Компоненты ТС** (детали, узлы), если они влияют на безопасность:
   - Тормоза, рулевое управление, амортизаторы
   - Шины
   - Светотехника
   - Стёкла
   - Кузовные детали (сертифицируемые)

И **НЕ распространяется** на:
- Декоративные аксессуары (накладки, чехлы, ароматизаторы)
- Электроника без отношения к управлению ТС (магнитолы, видеорегистраторы)
- Расходники общего назначения (масла, лампочки — отдельные регламенты)

## Документы для запчастей под ТР ТС 018/2011

| Тип запчасти | Документ |
|--------------|----------|
| **Влияет на безопасность ТС** (тормоз. диски, амортизаторы) | Сертификат соответствия ТР ТС 018/2011 |
| **Косвенно влияет** (двигатель, генератор) | Декларация соответствия |
| **Не влияет** (декоративные, технологические) | Отказное письмо |
| **Шины** | Отдельный сертификат + маркировка ЧЗ |

## Алгоритм классификации

Скрипт `_modules/06-certification-legal/scripts/classify_by_legislation.py`
автоматизирует процесс:

```bash
python _modules/06-certification-legal/scripts/classify_by_legislation.py my-skus.csv
```

Логика:
1. Проверка ТН ВЭД по перечню ПП РФ № 2425
2. Проверка по приложениям ТР ТС 018/2011 (что считается «компонентом ТС»)
3. Классификация: СС / ДС / СГР / Отказное

## Особенности продажи на МП

### Wildberries
- Категория «Автозапчасти» требует загрузки документов соответствия
- Без документов — карточка не пройдёт модерацию

### Ozon
- Аналогичная схема + проверка ОЕМ-номеров на соответствие
- Проверка через `_modules/06-certification-legal/scripts/check_ozon_requirements.py`

## Особенности для импорта

При ввозе компонентов ТС из Китая/других стран ЕАЭС:
- Если есть сертификат ТР ТС 018/2011 — можно ввозить без доп. процедур
- Если нет — оформлять при ввозе (либо на партию, либо на серийное производство)
- ТН ВЭД код влияет на пошлины (типично 5-15% для автозапчастей)

## Чек-лист (для селлера автозапчастей)

- [ ] Ассортимент классифицирован по ТР ТС 018/2011 + ПП РФ № 2425
- [ ] Для каждой позиции определён нужный документ (СС / ДС / Отказное)
- [ ] Документы оформлены и загружены в карточки МП
- [ ] При импорте — документ ТР ТС 018/2011 есть в составе таможенных документов
- [ ] У себя — оригиналы документов (Роспотребнадзор может проверить)
