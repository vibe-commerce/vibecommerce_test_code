# 152-ФЗ «О персональных данных» — basics

Last Updated: 2026-05-29
Источник: [Гарант — 152-ФЗ](https://base.garant.ru/12148567/)

## Что регулирует

Обработку **персональных данных (ПДн)** физлиц: сбор, хранение, обработку,
передачу, уничтожение. Распространяется на любую организацию (включая ИП),
обрабатывающую ПДн.

## Что считается ПДн

- ФИО, дата рождения
- Адрес, телефон, email
- Паспортные данные
- Платёжная информация (номер карты — частично ПДн)
- IP-адрес (по российской судебной практике — ПДн)
- Любая информация, связанная с конкретным физлицом

## Базовые обязательства селлера

### 1. Уведомление в Роскомнадзор
- При сборе ПДн через сайт/приложение нужно подать уведомление в РКН (до начала обработки)
- Услуга бесплатная, подаётся через [pd.rkn.gov.ru](https://pd.rkn.gov.ru/)
- Срок рассмотрения: 30 дней

### 2. Политика конфиденциальности
- Обязательна на сайте/в приложении, **где собираются ПДн**
- Должна быть доступна по прямой ссылке
- Содержит: цели обработки, перечень ПДн, сроки хранения, права субъекта

### 3. Согласие на обработку ПДн
- Должно быть **информированным, конкретным, добровольным**
- Если оформление = чекбокс — НЕ должен быть pre-checked
- Хранится 5 лет после прекращения обработки

### 4. Локализация ПДн в РФ
- Сервер с базой ПДн **должен находиться в РФ**
- Исключения для трансграничной передачи — отдельная процедура с РКН

### 5. Защита ПДн
- Технические меры: шифрование, разграничение доступа, журналирование
- Организационные меры: назначить ответственного, инструкции для сотрудников

## Штрафы (актуальные на 2025)

| Нарушение | Штраф для ИП |
|-----------|---------------|
| Нет уведомления в РКН | 6000-10000 ₽ |
| Нет политики конфиденциальности | 30000-50000 ₽ |
| Нет согласия / pre-checked checkbox | 30000-50000 ₽ |
| Утечка ПДн (>1000 субъектов) | 100000-300000 ₽ + штраф юрлицу до 18 млн (2025!) |
| Нелокализация в РФ | 1-6 млн ₽ |

⚠️ С 2025 года ужесточены штрафы за утечки.

## Чек-лист соответствия (для селлера)

- [ ] Уведомление в РКН подано (для сайта с формами)
- [ ] Политика конфиденциальности на сайте + в карточке Я.Маркет/Ozon (для DTC — обязательно)
- [ ] Чекбокс согласия не pre-checked
- [ ] Согласия хранятся (в БД, на сервере в РФ)
- [ ] Назначен ответственный за ПДн (для ИП — сам ИП)
- [ ] Доступ к БД ПДн только у уполномоченных лиц
- [ ] Бекапы шифруются

## Особенности для МП-селлеров

- **Карточка товара WB/Ozon/ЯМ:** ПДн обрабатывает площадка, селлер — обработчик второго уровня
- **Чаты с покупателями:** ПДн (имя, телефон) → обрабатывать по 152-ФЗ
- **Свой сайт (DTC):** полная ответственность селлера
- **CRM с базой клиентов:** обязательна локализация в РФ
