## Базовая шпаргалка

### Alibaba (англоязычный)
- Подходит для **первой пробы** (есть Trade Assurance — гарантия сделки)
- MOQ (min order qty) — высокий, торгуйся
- Logistics: можно через Alibaba.com Logistics или своим экспедитором
- Риски: подмена товара, задержки на таможне

### 1688 (китайский)
- **Дешевле Alibaba** на 30-50%, но нужен посредник (карго, экспедитор)
- Сайт на китайском — нужен переводчик / посредник
- MOQ ниже, чем на Alibaba
- Риски: нет Trade Assurance, оплата через посредника

### Российские оптовики
- Меньше маржа, но быстрее (нет таможни, ВЭД)
- Хорошо для теста ниши без вложений в импорт
- Avito B2B / Поставщики.ру / OptList

## Чек-лист «выбор поставщика»

- [ ] MOQ соответствует моему бюджету?
- [ ] Срок поставки укладывается в финансовый цикл?
- [ ] Есть сертификаты (если категория требует)?
- [ ] Возможен sample-order для теста качества?
- [ ] Есть отзывы / Trade Assurance / эскроу?
- [ ] Себестоимость с учётом логистики + таможни даёт нужную маржу (см. модуль 02)?
