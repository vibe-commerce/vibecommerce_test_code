# `backlog/archive/done/` — реализованные брифы и планы

Last Updated: 2026-05-02

## Что здесь

Брифы и планы, которые **уже реализованы**. По правилу lifecycle
(`ideas → briefs → plans → код → documentation`) реализованные документы
переезжают сюда — для:

- истории решений (почему был выбран такой подход),
- референсов из changelog (`_changelogs/0.X.Y-…` ссылаются на план),
- обучения новых форкеров (как выглядит «правильный» план реализации).

## Когда переносить сюда

Документ переезжает в `done/` **после полной реализации** — то есть:

- Все acceptance criteria выполнены.
- Изменения закоммичены и запушены.
- Changelog запись создана.
- Связанная фича упомянута в `documentation/`.

## Когда НЕ переносить

- Фича ещё в работе — оставь в `briefs/` или `plans/`.
- Идея отклонена / отказались — в `archive/rejected/`, не сюда.

## Структура

В `done/` могут жить и брифы, и планы — оба исхода lifecycle:

```
archive/done/
├── 2026-05-02-feature-x-brief.md   (если был только бриф)
├── 2026-05-02-feature-y-plan.md    (если был только план)
└── 2026-05-02-feature-z/            (если были оба + spec)
    ├── brief.md
    ├── plan.md
    └── tech-spec.md  (опц., копия из _specs/)
```
