## 2. СОХРАНИТЬ КАК РЕФЕРЕНСЫ (перенести в REFERENCES/, потом удалить исходные папки)

### 2.1. PRJ_PRICING → `REFERENCES/price_elasticity/`

Отличный пример анализа ценовой эластичности: скрипт + документация + графики.

**Что сохраняем:**
- `price_elasticity.py` — скрипт анализа (arc elasticity, log-linear модель, 5 типов графиков)
- `README.md` — документация методологии (формулы, формат данных, интерпретация)
- `reports/` — примеры выходных графиков
- `mpmgr/README.md` — документация по репрайсеру MP Manager

**Ценность:** Готовый инструмент для клиентов. Можно взять данные любого клиента и посчитать эластичность.

### 2.2. PRJ_ВЫБОР_НИШИ → `REFERENCES/niche_selection/`

Содержит две ценные вещи:

**a) Методология выбора ниши** (`niche-selection-plan.md`):
- 6 фаз: критерии → генерация ниш → скоринг → глубокая проверка → тест → решение
- Скоринг-матрица с весами (объём рынка 20%, конкуренция 20%, маржинальность 20%, тренд 15%, барьер 10%, сезонность 10%, экспертиза 5%)
- Бюджет тестового запуска ~300 тыс. с разбивкой по статьям
- Критерии успеха теста (выкупаемость >70%, CTR >5%, CR >5%)

**b) Справочник процента выкупа по категориям** (`add_buyback_rate.py`):
- 100+ категорий с процентами выкупа (от 32% купальники до 98% цифровые товары)
- Источники: GuruSeller, рыночные данные 2025
- Полезно при оценке ниш для новых клиентов

**Что сохраняем:**
- `niche-selection-plan.md` — методология
- `add_buyback_rate.py` — справочник выкупа (данные в коде)
- CSV-файлы НЕ сохраняем (устаревшие выгрузки)

### 2.3. PRJ_ВОРОНКА → `TEMPLATES/jtbd_card_prompt.txt`

**ВАЖНО:** Сначала скопировать промпт в TEMPLATES/, потом удалить PRJ_ВОРОНКА/.
