# `_status/` — текущее состояние проекта

Last Updated: 2026-05-29

## Что здесь

- `PROJECT_STATUS.md` — общий обзор статуса (фазы, блокеры, что в работе)

Workflow упрощён до `local` + `main` — отдельных DEV/PROD статусов нет.

## Зачем

В отличие от `_changelogs/` (история — что **было**), этот каталог про
**сейчас**: что развёрнуто, что в очереди, что блокирует. Аналог
status-page, но в md-формате.

## Как пользоваться

- Обновляй после каждого крупного шага апгрейда (помогает `/docs` скилл)
- Записи короткие, без истории; история в `_changelogs/`
