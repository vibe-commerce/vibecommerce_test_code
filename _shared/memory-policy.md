# Memory Policy

Last Updated: 2026-05-29

## Что писать в `_shared/MEMORY.md`

✅ **Стабильные факты о проекте:**
- Структура и принципы (workflow, тиринг, лицензия)
- Активные правила
- Decisions log (что и почему решено)
- Текущая фаза работы

✅ **Кросс-сессионные insights** — то, что должно пережить рестарт чата.

## Что НЕ писать в `_shared/MEMORY.md`

❌ **Личные данные пользователя** — это `_private/` (gitignored)

❌ **Эфемерные детали текущей сессии** — это `AGENDA.md`

❌ **История изменений** — это `_changelogs/CHANGELOG.md`

❌ **Реальные клиентские факты** — это `real-commerce_code/` (отдельный приватный репо)

❌ **Reusable code patterns** — это `_modules/<N>/scripts/` или `.claude/skills/`

## Когда обновлять

- При принятии важного решения архитектуры/тиринга → раздел Decisions log
- При смене фокуса фазы → раздел «Что в работе»
- При обнаружении нового открытого вопроса → раздел «Открытые вопросы»

## Когда чистить

Раз в квартал:
- Decisions log: оставить только actively-relevant (старые → в _changelogs/)
- «Что в работе»: удалить завершённые фазы
- «Открытые вопросы»: либо закрыть, либо отметить как deprioritized
