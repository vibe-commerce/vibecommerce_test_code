# README в каждой подпапке — навигационная память репо

Last Updated: 2026-05-01

> Репозиторий — это не дерево файлов, а **граф знания**.
> README — это узлы графа: что здесь лежит, зачем, куда идти дальше.

## Правило

В **каждой нетривиальной подпапке** должен быть `README.md`.

«Нетривиальная» = больше 3 файлов **или** содержит файлы, чьё назначение
не очевидно из имени папки.

«Тривиальная» = `tests/__pycache__/`, `node_modules/`, `dist/`, или
папка с одним файлом-самоописанием.

## Что должно быть в README подпапки

Минимум 4 секции:

```markdown
# <название> — <одно-строчное описание>

## Что здесь
<что лежит в этой папке: список файлов или категорий с пояснением>

## Зачем
<какую проблему решает эта папка; роль в проекте>

## Как пользоваться
<как добавлять файлы / менять / удалять; конвенции имён>

## Связанные
<ссылки на родительский README, на смежные папки, на скиллы>
```

## Зачем это нужно

1. **Для AI-агента** — он читает README как контекстный указатель.
   Без README он либо галлюцинирует роль папки, либо игнорирует её.
2. **Для нового человека** — попадает в папку и за 30 секунд понимает
   роль, не читая 50 файлов.
3. **Для тебя через 3 месяца** — забыл, что в `_evals/` хранится — открыл
   README, вспомнил.
4. **Для поиска** — Claude Code по символам имён не очень, по тексту
   README — хорошо.

## Иерархия README

```
README.md (корень)
    │
    ├─→ ссылается на _practices/README.md (как работать)
    ├─→ ссылается на documentation/README.md (факты)
    ├─→ ссылается на _specs/README.md (планы)
    │
    └─→ each subfolder has its own README pointing to parent
```

Каждый README **обязан** иметь обратную ссылку на родительский
(в секции «Связанные» или «Навигация»).

## Антипаттерны

❌ **README состоит из одной строки** — «здесь скрипты». Бесполезно.
❌ **README не обновляется при добавлении новых файлов** — со временем
   врёт. Включи в этап «Документация» проверку.
❌ **README дублирует содержимое родителя** — должен дополнять, не
   копировать.
❌ **README с битыми ссылками** — проверяй после рефакторинга папок.
