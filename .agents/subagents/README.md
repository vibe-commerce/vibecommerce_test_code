# `.agents/subagents/` — YAML-определения суб-агентов (источник)

Last Updated: 2026-06-02

## Что здесь

YAML-определения суб-агентов — единый источник правды. Из них
генерируются `.claude/agents/*.md` (для Claude Code) и
`.codex/agents/*.toml` (для OpenAI Codex).

## Как пользоваться

- Правь суб-агентов только здесь
- После изменений — `make sync-agents` для перегенерации конфигов
