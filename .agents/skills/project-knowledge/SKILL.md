# project-knowledge — база знаний шаблона EMPTY_code

CLAUDE.md содержит только critical rules и навигацию. Полный контекст — в reference-файлах ниже.

## Когда читать что

| Задача | Файл |
|--------|------|
| Понять структуру репо, где что лежит, дерево папок | `references/architecture.md` |
| Понять Git-workflow (ветки, коммиты, синхронизация, deploy) | `references/workflow.md` |
| Узнать конвенции именования, теги [CANONICAL]/[REF]/[CONFIRMED]/[PLACEHOLDER], правила README | `references/patterns.md` |
| Понять жизненный цикл документа (idea → brief → spec → код → documentation) | `references/lifecycle.md` |

## Использование

При первой встрече с задачей по структуре / git / lifecycle — прочитай соответствующий
reference-файл. Не пытайся угадать — все правила зафиксированы.

При создании новых файлов — сверяйся с `patterns.md` (имена, формат дат, теги).
