# patterns.md — конвенции именования, теги, README

Last Updated: 2026-05-01

## README.md в каждой папке (Memory Bank)

В **каждой подпапке** проекта — README.md с описанием содержимого. Это «карта памяти»
структуры. Без неё структура протухает за 2 недели.

### Шаблон README

```markdown
# {Название папки} — {краткое назначение}

Last Updated: YYYY-MM-DD

## Что здесь

- `файл.md` — что это
- `подпапка/` — что там

## Как пользоваться

1–3 предложения о том, как работать с папкой.

## Связанные

- Родитель: [`../README.md`](../README.md)
- Дети: список вложенных папок (если есть)
```

### Императив

**При добавлении/изменении/удалении/переименовании файла — обязательно обнови
`README.md` в затронутой папке.** Меняешь иерархию — обнови README на всех
уровнях, которые ссылаются на изменённый путь. Обнови `Last Updated:` в шапке.

## Теги для документов

| Тег | Значение |
|-----|----------|
| `[CANONICAL]` | Единственный авторитетный источник по теме |
| `[REF: path#section]` | Кросс-ссылка вместо дублирования содержимого |
| `[CONFIRMED: source]` | Проверенная информация с указанием источника |
| `[PLACEHOLDER: owner]` | Заглушка, требует заполнения; владелец — кто заполнит |

### Принцип «No orphan statements»

Каждое утверждение в документации должно прослеживаться к источнику. Если факт
нельзя подтвердить — пометь `[PLACEHOLDER]`, **не выдумывай**.

При изменении источника — проверь, что на него ссылается:
```bash
grep -r "имя-источника" .
```

## Имена файлов

### Правила

| Тип файла | Формат |
|-----------|--------|
| Markdown / документы | `lowercase-kebab-case.md` (латиница) |
| Датированные | `YYYY-MM-DD-описание.md` |
| Python | `snake_case.py` |
| Конфиги | `kebab-case.yaml` или `snake_case.yaml` (по фреймворку) |
| Кириллица | допустима только для имён людей, транскриптов, исторических документов |

### Запрещено

- ❌ Пробелы в именах файлов (заменять `-` или `_`)
- ❌ Суффиксы `_v2`, `_v3`, `_final`, `_FINAL2` (используй git)
- ❌ Слова `copy`, `old`, `backup` в именах (для архива → `_archive/` подпапка)
- ❌ Эмодзи в именах файлов
- ❌ Спецсимволы кроме `-`, `_`, `.`

## Качество контента

- Не выдумывай данные — только подтверждённая информация
- Указывай источники цифр и метрик
- Дата обновления: `Last Updated: YYYY-MM-DD` в шапке каждого документа
- Принцип DRY на уровне доков: не копируй содержимое — ставь `[REF: path]`

## FACTS.md

- Корневой `FACTS.md` — стабильные общепроектные факты
- Внутри подпапок может быть свой `FACTS.md` для модульных фактов (опционально)
- Меняется редко (квартал-год); если меняется часто — это не FACTS, а AGENDA

## Anti-patterns

- ❌ Создал файл — не обновил README родительской папки
- ❌ Удалил папку — оставил ссылки на неё в README родителя
- ❌ Скопировал кусок документации в 3 места вместо `[REF:]`
- ❌ Утверждение без источника / не помечено `[PLACEHOLDER]`
- ❌ Last Updated не обновлён после правки
- ❌ Файл с именем `report_FINAL_v2.md` (история — задача git)
