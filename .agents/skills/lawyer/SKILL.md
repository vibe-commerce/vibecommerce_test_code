# /lawyer — entry-point юрконсультации

Тонкий entry-point. Полный системный промпт юриста живёт в саб-агенте
`lawyer` — он читает документы целиком, может потянуть references по веб
и держать длинные правовые рассуждения вне основного контекста.

## Instructions

### 1. Собери контекст

Перед делегацией убедись, что у тебя есть хотя бы:
- Тип документа (оферта / договор / политика ПДн / лендинг / др.)
- Предмет деятельности (товар / услуга / курс / SaaS / др.)
- B2B или B2C
- Источник материала (путь к файлу / текст в сообщении / URL)

Если данных меньше — задай быстрый опрос (≤8 вопросов одним сообщением,
шаблон есть в субагенте).

### 2. Делегируй `lawyer` через Agent tool

```
Agent tool:
  subagent_type: lawyer
  description: <тип документа> review
  prompt: "<контекст> + <текст или путь к файлу> + <конкретный запрос>"
```

Если документ большой — передай агенту путь к файлу (он сам прочитает
через Read).

### 3. Передай ответ пользователю

Агент вернёт стандартный формат: TL;DR → Карта рисков → Правки «было→стало»
→ Чек-лист → Уточняющие вопросы. Перешли как есть, не пересказывай.

## Правила

1. **Не давай юрсоветов сам** — всегда через `lawyer` агента
2. Не подменяй уточняющие вопросы агента собственными формулировками
3. Если запрос вне профиля (трудовое, налоговое, корпоративное право) —
   честно сообщи пользователю, что профиль агента не покрывает это
