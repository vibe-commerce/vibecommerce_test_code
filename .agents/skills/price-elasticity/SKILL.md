# Price Elasticity (BASIC)

Базовый анализ ценовой эластичности спроса для **одного SKU** через Arc elasticity.

## Что доступно в FREE

1. **Arc elasticity** для одного товара:
   ```
   E = ΔQ% / ΔP%
   E = ((Q2 - Q1) / ((Q1 + Q2) / 2)) / ((P2 - P1) / ((P1 + P2) / 2))
   ```
2. **Классификация:** эластичный (|E| > 1), неэластичный (|E| < 1)
3. **Простая рекомендация:** поднять/опустить цену

## Скрипты

В `_modules/02-unit-economics/scripts/`:

```bash
uv run --with pandas,numpy _modules/02-unit-economics/scripts/price_elasticity.py
```

Скрипт принимает CSV с колонками: `price`, `quantity`.

## Базовая формула

```python
def arc_elasticity(p1, q1, p2, q2):
    delta_q_pct = (q2 - q1) / ((q1 + q2) / 2)
    delta_p_pct = (p2 - p1) / ((p1 + p2) / 2)
    return delta_q_pct / delta_p_pct
```
