# `_changelogs/` — история релизов шаблона

Last Updated: 2026-05-29

## Что здесь

Один файл `CHANGELOG.md` с историей релизов шаблона по semver.
Workflow упрощён до `local` + `main` — отдельных DEV/PROD changelog'ов нет.

## Зачем

- Быстро посмотреть «что изменилось от 0.2.0 к 0.3.0» без копания в `git log`
- Документировать ломающие изменения структуры для форков
- Сохранять security-критичные миграции (например, удаление токенов из истории)

## Как пользоваться

Записи добавляй **сверху** (newest first). Формат:

```markdown
## X.Y.Z — YYYY-MM-DD

{MAJOR|MINOR|PATCH} — короткое описание сути.

### Added
- ...

### Changed
- ...

### Removed
- ...

### Security
- ...

### Migration (если нужно для форков)
1. ...
```

Скилл `/docs` помогает автогенерировать запись после крупного апгрейда.

## Semver правило (шаблон template)

- **MAJOR (1.0.0)** — ломающее изменение структуры
- **MINOR (0.X.0)** — новая обязательная секция/файл/скилл
- **PATCH (0.0.X)** — фиксы

См. [CLAUDE.md](../CLAUDE.md) раздел «Semver для шаблона».
