# `_handoffs/` — артефакты сдачи сессии

Last Updated: 2026-06-02

## Что здесь

Артефакты сдачи сессии — вывод скилла `/handoff`. Файлы с датой
в имени фиксируют: что сделано, где остановились, что не доделано,
конкретные следующие шаги.

## Как пользоваться

- Файлы создаёт скилл `/handoff` в конце сессии
- Следующая сессия читает свежий handoff для подхвата контекста
