# `.claude/data/` — runtime-память скиллов

Last Updated: 2026-06-02

## Что здесь

Runtime-данные, которые скиллы и правила пишут в процессе работы.
Главный файл — `error-log.md`, куда правило `error-learning` записывает
симптом / причину / исправление / предотвращение после багов и провалов.

## Как пользоваться

- Не редактируй вручную без необходимости — это лог сессий
- При старте сессии проверяй `error-log.md`, если задача связана с прошлыми ошибками
