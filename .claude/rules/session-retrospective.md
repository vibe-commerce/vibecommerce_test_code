# Session Retrospective

## Маркеры в процессе работы

При обнаружении проблем или важных решений — оставляй маркеры:
- В коде: `# TODO: {что нужно улучшить}`
- В коммитах: упоминай контекст решения
- В AGENDA.md: фиксируй ключевые решения сессии

## Периодический анализ

Раз в неделю рекомендуется:
1. Запустить `/insights` — встроенный анализ Claude Code за 30 дней
2. Просмотреть HTML-отчёт с рекомендациями
3. Применить предложенные улучшения к скиллам и правилам

## При завершении сессии

Обнови AGENDA.md:
- Что сделано
- Ключевые решения
- Что осталось
- Маркеры для следующей сессии
