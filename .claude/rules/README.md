# `.claude/rules/` — активные правила сессии

Last Updated: 2026-05-29

## Что здесь

Семь правил, которые Claude Code применяет в каждой сессии:

- `plan-before-act.md` — **КРИТИЧНОЕ.** Перед нетривиальной правкой план в файл,
  согласование от человека, потом исполнение (см. ссылку из CLAUDE.md
  → раздел «КРИТИЧЕСКИЕ ПРАВИЛА»)
- `auto-backup.md` — после значимой работы предлагать бэкап в GitHub
- `error-learning.md` — после фиксов писать в `.claude/data/error-log.md`
  и обновлять CLAUDE.md если ошибка системная
- `session-retrospective.md` — маркеры в коде/коммитах + еженедельный `/insights`
- `cost-control.md` — лимиты на платные API (Apify, scrape.do, MPStats Pro),
  чтобы случайно не сжечь бюджет
- `marketplace-data-freshness.md` — rate limits + обновление кеша для
  WB/Ozon/ЯМ/MPStats API
- `legal-data-freshness.md` — мониторинг изменений 152-ФЗ, ЗоЗПП,
  ПП РФ № 2425, ТР ТС 018/2011

## Зачем

Правила — это **поведенческие гайды** для агента. Они инжектятся в системный
промпт через CLAUDE.md (раздел «КРИТИЧЕСКИЕ ПРАВИЛА» отсылает на правила).
Это место, где описаны конвенции, ритуалы, привычки команды/студента.

## Как пользоваться

- Один файл = одно правило с конкретной формулировкой триггера
- Структура: что → когда → что делать → что НЕ делать
- При добавлении нового правила — сослаться на него в CLAUDE.md

Правила — НЕ хуки. Хуки настраиваются в `.claude/settings.json` и
`.claude/hooks/`.
