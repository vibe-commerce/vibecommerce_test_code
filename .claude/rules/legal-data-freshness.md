# Legal Data Freshness

## Правило

При ответах на юридические вопросы (налоги, НДС, ЗоЗПП, маркировка, ПДн, реклама, 289-ФЗ) — **обязательно проверять актуальность** базы знаний `knowledge/`.

## Еженедельная проверка

Если `Last Updated` в файлах `knowledge/legal/` старше **7 дней**, перед ответом:

1. Предупредить пользователя о давности данных
2. Предложить актуализацию через скилл `ecom-legal` (аргумент «обновить»)
3. При критичных вопросах (штрафы, сроки, пороги НДС) — проверить через WebSearch

## Файлы базы знаний

| Файл | Тематика | Критичность |
|------|----------|-------------|
| `taxation-guide.md` | НДС, УСН, взносы, пороги | Высокая — ставки и пороги меняются |
| `certification-guide.md` | Сертификация, «Честный знак» | Высокая — новые категории ежеквартально |
| `consumer-protection-guide.md` | ЗоЗПП, возвраты, кассы | Средняя |
| `ecom-legal-compliance.md` | ПДн (152-ФЗ), реклама (38-ФЗ) | Высокая — штрафы увеличены |
| `platform-economy-guide.md` | 289-ФЗ, самозанятые, ИП/ООО | Средняя — закон вступает 01.10.2026 |
| `legal-calendar.md` | Календарь вступления в силу | Высокая — проверять еженедельно |

## Что проверять при актуализации

- Новые ФЗ и поправки для e-commerce (pravo.gov.ru)
- Изменения НДС/УСН (nalog.gov.ru)
- Новые категории маркировки (честныйзнак.рф)
- Штрафы ПДн и реклама (rkn.gov.ru, fas.gov.ru)
- Подзаконные акты к 289-ФЗ
- Изменения оферт маркетплейсов

## Первоисточники

Всегда начинать проверку с **официальных** источников:
- pravo.gov.ru — новые ФЗ
- nalog.gov.ru — налоги
- rkn.gov.ru — ПДн
- fas.gov.ru — реклама, антимонополия
- честныйзнак.рф — маркировка

Полный реестр: `knowledge/legal/legal-monitoring-registry.md`
