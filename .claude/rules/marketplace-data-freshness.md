# Marketplace Data Freshness

## Правило

При любых расчётах юнит-экономики, финансовых расчётах, анализе ниш или подготовке карточек товаров — **обязательно учитывать**:

1. **СПП (Скидка WB)** — снижает цену для покупателя за счёт маркетплейса
2. **Соинвест Ozon** — компенсация через баллы, налоговые риски
3. **Спецусловия WB** — программа «Уровни продавцов» + программа сотрудничества
4. **Скидки Яндекс Маркета** — прямые скидки + баллы Маркета

Полная документация: `knowledge/marketplaces/marketplace-discounts-guide.md`

## Еженедельная проверка

Если с момента последнего обновления `knowledge/marketplaces/marketplace-discounts-guide.md` прошло **более 7 дней**, перед финансовыми расчётами:

1. Проверить актуальность данных через WebSearch
2. Обновить файл при расхождениях
3. Обновить `Last Updated`

## Что проверять

- Комиссии (КВВ) WB, Ozon, Яндекс Маркет
- Тарифы логистики и хранения
- Условия программ лояльности (уровни, сотрудничество)
- Налоговые изменения (НДС с 2026)

## Первоисточники

Всегда начинать проверку с **официальных** источников:
- WB: seller.wildberries.ru
- Ozon: docs.ozon.ru
- Яндекс Маркет: yandex.ru/support/marketplace
