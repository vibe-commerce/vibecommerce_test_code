# Plan Before Act

План — в файл, согласование — от человека, и только потом исполнение.
Без явного сигнала AI **ждёт**, не действует.

## Триггер

Перед любой нетривиальной правкой. Нетривиальная — это всё, что **не**:

- опечатка / косметика / переформулировка одной строки
- запрос на чтение / поиск / диагностику без изменений
- единичная правка в одном файле <10 строк, явно описанная пользователем

Если сомневаешься — **планируй**.

## 4 шага

1. **Записать план в файл.**
   - Лёгкая фича / правка → `backlog/plans/<YYYY-MM-DD>-<slug>.md`
     (по шаблону `_specs/templates/plan.md`)
   - Если бриф ещё не написан, а фича заметная — сначала
     `backlog/briefs/<YYYY-MM-DD>-<slug>.md` (по `_specs/templates/brief.md`),
     потом `plans/`
   - Архитектура / большая фича — план всё равно в `backlog/plans/`,
     плюс tech-spec/user-spec в `_specs/<feature>/`
   - В плане: цель, контекст, подход, риски, чек-лист задач, метрика успеха.

2. **Показать пользователю.** Дать путь к файлу + 3-5 строк краткого
   содержания (не пересказывать весь план).

3. **Ждать явного сигнала-согласования.** Принимаемые сигналы:
   «делай» / «ок» / «согласовано» / «поехали» / «approved» / «go» (или
   эквивалент). По дефолту — **ждать**, не действовать. Уточнения и
   вопросы пользователя — НЕ согласование.

4. **Отклонение от плана → обновление файла плана.** Если в процессе
   реализации план пришлось менять — сначала правишь файл плана, затем
   продолжаешь. Не отклоняйся молча.

## Антипаттерны

- ❌ «Приступаю к реализации» сразу после написания плана, без сигнала.
- ❌ План «в голове» вместо файла — теряется на следующей сессии.
- ❌ Согласовали Фазу 0 — поехал делать Фазу 1 без нового сигнала.
- ❌ План разошёлся с реализацией, файл не обновлён.
- ❌ Чек-лист задач написан в `backlog/briefs/<slug>.md` (это сигнал
  создать `plans/<slug>.md`, бриф = «зачем», план = «как»).
- ❌ План в `_specs/<feature>/plan.md` — со 0.5.0 план только
  в `backlog/plans/<slug>.md`. В `_specs/` живут спецификации
  архитектуры (tech-spec, user-spec, ADR).
