# Apify Cost Control

## Правило

**ОБЯЗАТЕЛЬНО** перед каждым вызовом Apify API (MCP или Python-скрипт):

1. **Оценить стоимость** запроса
2. **Проверить баланс** (`uv run --with httpx,python-dotenv scripts/apify/client.py --check`)
3. **Показать пользователю** оценку и баланс
4. **Дождаться явного подтверждения** — без "да"/"ок"/"запускай" НЕ отправлять запрос

## Формат уведомления

```
Apify запрос:
- Actor: <имя актора>
- Запрос: <параметры>
- Оценка стоимости: ~$X.XX
- Баланс: $X.XX / $5.00 (free plan)
- Остаток после запроса: ~$X.XX

Запустить? (да/нет)
```

## Оценки стоимости (эмпирические)

| Actor | Стоимость | Единица |
|-------|----------|---------|
| `happitap/alibaba-product-scraper` | ~$0.14 | 50 товаров (1 страница) |
| `devcake/alibaba-products-scraper` | ~$0.25 | 48 товаров (1 страница) — proxy fail на free |
| AliExpress скраперы | Платные | Требуют аренды |

**Формула оценки:** `стоимость ≈ $0.14 × количество_страниц × количество_запросов`

## Лимиты

- Free план: **$5.00/мес** (обновляется каждый billing cycle)
- Рекомендуемый лимит на запуск: **$1.00** (--max-cost 1.0)
- При остатке < $1.00 — предупредить о скором исчерпании

## Проверка баланса

```bash
uv run --with httpx,python-dotenv scripts/apify/client.py --check
```

## Применяется к

- Прямые вызовы REST API через Python-скрипты (`scripts/apify/scrape_alibaba.py`)
- MCP-вызовы Apify Actors (после активации MCP-сервера)
- Любые другие обращения к `api.apify.com`
