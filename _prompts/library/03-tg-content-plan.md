# Промпт: Контент-план TG-канала бренда

## Когда использовать

- Запуск нового TG-канала бренда селлера
- Перезапуск спящего канала
- Адаптация плана под сезонность

## Промпт

```
Ты — SMM-контент-маркетолог для e-commerce селлеров.

Дано: бренд / товары / ЦА / цель канала (продажи / прогрев / лояльность).

Сделай контент-план на месяц (4 недели) для Telegram-канала бренда.

Структура:
- 4 недели × 5 постов/неделю = 20 постов
- Тематический микс по системе 80/20:
  * 60% — Полезный контент (ЦА получает выгоду от чтения)
  * 25% — Социальное доказательство (отзывы, кейсы, истории)
  * 15% — Продажные посты (с CTA на покупку)

Для каждого поста:
- Дата (день недели + время публикации)
- Тип (Полезный / Соц.доказательство / Продажа)
- Заголовок (привлекательная первая строка)
- Краткое содержание (3-5 предложений основной мысли)
- Призыв (что делать читателю)
- Идея для иллюстрации (фото / иллюстрация / скриншот / видео)

Принципы:
- Без воды и общих фраз ("счастье от шопинга" — мусор)
- Один пост = одна мысль
- Если есть факт — должна быть цифра/источник
- Учитывай сезонность (праздники месяца)
- Формат TG: короткие абзацы, эмодзи, без перегруза смайлами

Дополнительно:
- 3 идеи для Stories
- 2 идеи для совместных публикаций с другими каналами
```

## Пример

### Вход
```
Бренд: BRIGHTSLEEP (постельное бельё натуральное)
ЦА: Женщины 28-45, городские, доход средний+, заботятся о здоровье и эстетике дома
Цель канала: прогрев + продажи
Месяц: Февраль
```

### Выход (фрагмент)
```
НЕДЕЛЯ 1 — Тема "Качество сна"

Пн, 19:00 — Полезный
Заголовок: "Почему ты не высыпаешься, даже если спишь 8 часов"
Содержание: 4 главные причины (телефон в спальне, температура > 19°, синтетическое бельё, поздняя еда). Что говорят сомнологи. Какая часть в окружении сна.
Призыв: "Сохрани, чтобы проверить вечером 👇"
Иллюстрация: инфографика 4-х причин

Ср, 19:00 — Соц.доказательство
Заголовок: "Прошла бессонница после смены белья — Анастасия, 34"
Содержание: история покупательницы. Что было до. Что сделала (купила лён). Что стало через 2 недели.
Призыв: "Кому близко — лайк ❤️"
Иллюстрация: фото комплекта в интерьере покупательницы

Пт, 19:00 — Полезный
Заголовок: "Сколько служит постельное бельё — таблица"
Содержание: ресурс хлопка/льна/сатина в стирках. Когда менять. Признаки износа.
Призыв: "Какое бельё у тебя сейчас? Напиши в комменты"
Иллюстрация: таблица сравнения

Сб, 12:00 — Продажа
Заголовок: "ХИТ месяца — Льняной комплект 1.5-спального — скидка 20%"
Содержание: 3 главные выгоды, размеры в наличии, акция до 28.02.
Призыв: "В карточке → vibecommerce.ru/lentbed (ссылка на WB/Ozon)"
Иллюстрация: товар на белом фоне + плашка "-20%"

Вс, 11:00 — Полезный
Заголовок: "Как правильно стирать лён, чтобы служил 5+ лет"
Содержание: 5 правил ухода (40-60°C, сушка в развёрнутом виде, без хлора, разглаживание во влажном виде, хранение).
Призыв: "Какие у тебя любимые лайфхаки по уходу? 👇"
Иллюстрация: пошаговая инфографика
```
