# `_prompts/library/` — каталог промптов по тематикам

Last Updated: 2026-05-29

## Что здесь

Узкие тематические промпты для конкретных задач селлера.
В отличие от `roles/` (стабильные «персоны»), `library/` — это **одноразовые
промпт-инструменты** под конкретный кейс.

## Категории

| Категория | Что внутри | FREE/VIP |
|-----------|------------|----------|
| **Карточки товаров** | SEO-описание, оптимизация фото, A/B-тесты | FREE basics |
| **Реклама** | Креативы, тексты объявлений, ретаргетинг | FREE basics |
| **Контент** | TG-посты, Reels, email-рассылки | FREE basics |
| **Аналитика** | Шаблоны разбора отчётов МП | FREE basics |
| **Поставщики** | Шаблоны писем поставщикам (Alibaba, 1688) | FREE basics |

## Структура файла промпта

```markdown
# Промпт: <название>

## Системное сообщение
{что задать AI как роль}

## Промпт пользователя (шаблон)
{что вставлять с переменными {placeholder}}

## Пример использования
{реальный пример input/output}

## Связанные
{ссылки на role или модуль}
```

## 📈 Углубление в `vibecommerce_vip_code`

Полная библиотека premium-промптов:
- **Tactical playbooks** — пошаговые сценарии под конкретные ситуации
- **AJTBD-промпты** (9 штук) — см. [`../jtbd/`](../jtbd/)
- **Финансовые промпты** — для разбора P&L, ДДС, оптимизации налогов
- **Юридические промпты** — оферта, политика, шаблоны B2C-договоров
