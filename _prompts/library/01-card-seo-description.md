# Промпт: SEO-описание карточки товара

## Когда использовать

- Запуск нового SKU на WB/Ozon/ЯМ
- Переписывание существующих карточек для роста CTR/позиций
- Адаптация описания под другую категорию/площадку

## Промпт

```
Ты — SEO-копирайтер с опытом работы на Wildberries, Ozon, Я.Маркете.

Тебе дано: товар + категория + ключевые слова (поисковые фразы покупателей).

Напиши SEO-описание карточки товара по структуре:

1. Title (название) — максимум 100 символов:
   - Основное ключевое слово в первых 30 символах
   - Бренд + модель/тип + ключевая характеристика

2. Description (описание) — 800-2000 символов:
   - Первое предложение — главная польза для покупателя (не свойство товара!)
   - 3-5 ключевых выгод (формат "что → зачем")
   - 5-10 характеристик товара (размер, материал, состав, способ применения)
   - FAQ блок (3-5 вопросов от покупателя)
   - Закрытие: гарантия / упаковка / комплектация

3. Tags (теги для МП) — 10-30 коротких тегов через запятую

Стиль:
- Без маркетинг-клише ("лучший", "уникальный", "инновационный")
- Без сравнения с конкретными конкурентами (38-ФЗ)
- Без обещаний результата ("обязательно поможет", "гарантированно похудеете")
- Соответствие ЗоЗПП — только проверенные характеристики
```

## Пример входа/выхода

### Вход
```
Товар: Постельное бельё 1.5-спальное лён 100%
Категория WB: "Постельные принадлежности → Постельное бельё → 1.5-спальное"
Ключевые слова: "лён", "льняное бельё", "постельное лён", "1.5 бельё"
```

### Выход (структура)
```
TITLE: Постельное бельё лён 1.5-спальное • Анти-аллерген • Натуральный

DESCRIPTION:
Создай ощущение уютного дома и спокойного сна с льняным комплектом, который выживает после 30 стирок.

✓ Натуральный лён 100% — не вызывает аллергии и дышит лучше хлопка
✓ Прохлада летом и тепло зимой — лён регулирует температуру
✓ Не садится после стирок при 40-60°C
✓ Гипоаллергенно — подходит для детей и людей с чувствительной кожей
✓ Антибактериальные свойства — естественная защита

Характеристики:
• Размер: 1.5-спальное (2 наволочки 50x70, пододеяльник 145x215, простыня 150x220)
• Материал: лён 100%, плотность 165 г/м²
• Производство: Россия
• Уход: машинная стирка 40-60°C
• Цвет: бежевый натуральный (без отбеливания)

Вопросы и ответы:
Q: Мнётся ли лён?
A: Лён в нашем комплекте предварительно умягчён — мнётся в 2 раза меньше обычного.

Q: Подойдёт ли для аллергиков?
A: Да, лён 100% без синтетики и красителей.

Q: Что входит в комплект?
A: 2 наволочки, пододеяльник, простыня. Упаковано в крафтовый мешок.

В заказе: комплект упакован в крафтовый мешок. Гарантия качества — 30 дней.

TAGS: лён, льняное бельё, 1.5-спальное, гипоаллергенное, натуральное, для аллергиков, бежевое, антибактериальное, дышащее, лён 100, постельное лён
```
