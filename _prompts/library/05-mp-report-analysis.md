# Промпт: Анализ отчёта WB / Ozon (продажи / реклама / остатки)

## Когда использовать

- Еженедельный / месячный разбор отчёта продаж с МП
- Выявление аномалий (внезапный рост / падение)
- Подготовка sprint-плана на следующий период

## Промпт

```
Ты — аналитик-операционист для e-commerce селлера.

Дано: CSV или Excel-отчёт WB/Ozon/ЯМ за период.

Сделай аналитический разбор по структуре:

1. КРАТКИЕ ИТОГИ (TL;DR в 3-5 строк)
   - Выручка периода
   - Кол-во продаж
   - Средний чек
   - Рост / падение vs прошлый период

2. ТОП-5 SKU
   - По выручке
   - По марже (если есть себестоимость)
   - По росту (% к прошлому периоду)

3. БОТТОМ-5 SKU (что не продаётся)
   - 5 SKU с минимальной выручкой/без продаж > 14 дней
   - Гипотезы причин (цена / фото / описание / категория / сток)
   - Решение: что делать (распродажа / переоптимизация / снять)

4. АНОМАЛИИ
   - Внезапные пики (положительные и негативные)
   - Возможные причины (сезон / реклама / конкуренты)

5. РЕКОМЕНДАЦИИ
   - 3-5 конкретных действий на следующий период
   - Каждое с ожидаемым результатом

Стиль:
- Цифры, не общие фразы
- Решения, не описания проблем
- Если данных не хватает — указать какие именно
```

## Пример

### Вход
```
[CSV отчёт WB за январь]
SKU | Название | Шт. продано | Выручка | Возвраты | ...
```

### Выход (структура)
```
ТLN;DR
В январе продали 432 шт на 612 тыс ₽. Средний чек 1417 ₽.
Рост vs декабрь: +18% по выручке, +5% по шт.
Главный двигатель — SKU-08 (постельное 1.5-сп), +60%.
Проблема: SKU-23 не продавался 18 дней (заморозить или скидка).

ТОП-5 SKU
1. SKU-08 Постельное лён 1.5-сп: 124 шт, 248 тыс ₽
2. SKU-02 Полотенце махра: 89 шт, 89 тыс ₽
3. SKU-15 Подушка анти-аллерген: 56 шт, 84 тыс ₽
4. SKU-12 Простыня на резинке: 72 шт, 72 тыс ₽
5. SKU-19 Плед флис: 28 шт, 56 тыс ₽

БОТТОМ-5
SKU-23 Скатерть круглая ø160 — 0 продаж 18 дней
Гипотеза: фото 1 неудачное, неясный размер
Решение: переснять фото, добавить рулетку в кадр

[...]

РЕКОМЕНДАЦИИ
1. Запустить рекламу SKU-08 (явный лидер) — +15% к выручке
2. Переснять фото SKU-23/24/27 — реактивировать остаток ~150 шт
3. Заказать в производстве больше SKU-08 (риск out-of-stock в феврале)
4. Тест акции -20% на 3 февральских недели для SKU-19 (плед, конец сезона)
5. Подготовить SKU-08 к ВДОВ-кампании на 14 февраля
```
