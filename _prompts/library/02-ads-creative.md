# Промпт: Рекламный креатив для МП

## Когда использовать

- Запуск рекламной кампании на WB Promo / Ozon Performance / Я.Директ
- Тестирование разных подходов в баннерной/видеорекламе
- Адаптация одного креатива под разные платформы

## Промпт

```
Ты — копирайтер рекламных кампаний для e-commerce.

Дано: товар + ЦА (1-2 предложения) + целевая площадка (WB / Ozon / ЯМ / VK).

Сделай 3 варианта рекламного креатива:

ВАРИАНТ A — Эмоциональный (для прогретой аудитории)
- Hook (заголовок): эмоциональный триггер из 4-7 слов
- Body: история / польза для жизни покупателя (3-4 предложения)
- CTA: призыв к действию ("Получи", "Попробуй")

ВАРИАНТ B — Рациональный (для холодной)
- Hook: цифра / факт / результат
- Body: 2-3 ключевые характеристики + сравнение с альтернативами
- CTA: специальное предложение ("Скидка 30% — до 31.12")

ВАРИАНТ C — Социальное доказательство
- Hook: цитата отзыва ИЛИ "1000+ покупателей выбрали"
- Body: подтверждение результата + детали
- CTA: "Посмотри отзывы и присоединяйся"

Дополнительно для каждого варианта:
- Подсказка для изображения (что показать, главный визуал)
- Подсказка для видео (3-5 кадров, что в каждом)
- Размеры/форматы под платформу

Строго соблюдай:
- Без "лучший / № 1 / уникальный" (38-ФЗ → ФАС штраф)
- Без сравнения с конкретными конкурентами
- Без обещаний гарантированного результата
- Для интернет-рекламы — нужна маркировка ERID (упомяни, что обязателен)
```

## Пример

### Вход
```
Товар: Беспроводные наушники с шумоподавлением (TWS)
ЦА: Городские мужчины 25-40 лет, работа в open space + дорога в метро
Площадка: VK реклама
```

### Выход (структура)
```
ВАРИАНТ A — Эмоциональный
Hook: "Тишина в open space — на одно нажатие"
Body: Активное шумоподавление гасит шум коллег, кофемашины, кондиционера. Включи фокус-режим и впервые за рабочий день услышь свою мысль — а не чужой звонок.
CTA: Попробуй на 30 дней с возвратом
Visual: парень в наушниках в опен-спейсе на фоне расфокусированных коллег
Video: 1) шумный офис → 2) надевает наушники → 3) тишина → 4) фокус на ноутбуке → 5) логотип

ВАРИАНТ B — Рациональный
Hook: "До 30 часов автономной работы. ANC -28 дБ."
Body: Bluetooth 5.3, поддержка AAC + AptX HD. Шумоподавление активное (ANC) и пассивное. Зарядка 10 минут = 1.5 часа.
CTA: -25% по промокоду TWS25 до 31.12
Visual: вид сверху на наушники + смартфон с показанным заряд
Video: характеристики на чёрном фоне, по 1 в секунду

ВАРИАНТ C — Социальное доказательство
Hook: "1247 покупок за месяц • 4.8 ⭐"
Body: "Купил для метро — теперь не снимаю в офисе" — Дмитрий, IT-специалист. Микрофон с шумоподавлением для звонков. Защита IPX4 от дождя.
CTA: Посмотри 200+ отзывов в карточке
Visual: коллаж скриншотов отзывов
Video: листание отзывов → отзыв читается голосом → продукт в работе

⚠️ Для всех: интернет-реклама в РФ — обязателен токен ERID + пометка "Реклама" + название рекламодателя.
```
