# `_references/` — справочники и бенчмарки

Last Updated: 2026-05-01

## Что здесь

Внешние артефакты, на которые мы опираемся, но **не создаём**:
- Документации API, скачанные локально (если нужен offline-доступ)
- Бенчмарки и сравнения библиотек, которые делал сам
- Скриншоты конкурентских решений с пометками
- Расчёты «как они это делают» (reverse-engineered notes)
- Цитаты / выдержки из книг и статей по теме проекта

Имя: `<тема>-<NN>.md` или `<тема>/`. Пример: `auth-providers-comparison.md`,
`competitors/notion-pricing.md`.

Сейчас папка пустая — наполняется по мере работы.

## Зачем

Чтобы такие материалы не растворялись в Slack / закладках браузера.
Если на это решение потратили час исследования — сохрани результат тут,
а не «потом найду заново».

Отличие от `documentation/`:
- `documentation/` = факты **про наш проект**
- `_references/` = факты **про мир вокруг проекта**

## Как пользоваться

- **Один файл = одна тема справочника.**
- **Указывай источник:** URL, дата, кто доставал. Ссылки гниют —
  локальная копия с meta нужна.
- **Не клади:** скачанные PDF целиком (они в `_private/docs/`),
  скриншоты с PII (в `_private/data/`).
- **Удаление:** если справочник устарел >1 года и мы давно не открывали —
  выкинуть. Не пытайся быть всем архивом интернета.
