# 06 — Сертификация и юр.требования

Last Updated: 2026-05-29

## Главный вопрос

«Что нужно по закону для продажи?» — классификация товара по законодательству
РФ, требования маркетплейсов, выбор формы сертификации/декларирования.

## Методика

Скрипты в `scripts/` — **универсальная методика классификации товара**
по российскому законодательству:

- **ТР ТС 018/2011** — технический регламент Таможенного союза по безопасности
  колёсных транспортных средств (актуально для автотоваров)
- **ПП РФ № 2425** — Перечень товаров, подлежащих обязательной сертификации
  и декларированию
- Требования **Wildberries** к карточке (что обязательно указывать)
- Требования **Ozon** к карточке + сертификатам

## Скрипты

- `scripts/check_ozon_requirements.py` — проверка соответствия Ozon-требованиям
- `scripts/check_wb_requirements.py` — проверка соответствия WB-требованиям
- `scripts/classify_by_legislation.py` — классификация SKU по ПП РФ № 2425 + ТР ТС 018/2011
- `scripts/merge_classification.py` — объединение результатов классификации
- `scripts/validate_classification.py` — валидация финальной таблицы

> ⚠️ Скрипты универсальные, не привязаны к конкретному селлеру. Для запуска
> нужна своя выгрузка SKU (CSV: артикул + название + категория).

## Workflow

```
1. Выгрузить свой ассортимент из ЛК продавца (CSV)
2. Положить в my-project/05-legal/data/
3. python scripts/classify_by_legislation.py my-project/05-legal/data/skus.csv
4. Получить классификацию: сертификация / декларирование / СГР / отказное письмо
5. Проверить требования МП: python scripts/check_{wb,ozon}_requirements.py
6. Сохранить результат → my-project/05-legal/reports/
```

## Чек-лист «модуль закрыт»

- [ ] Свой ассортимент классифицирован по ПП РФ № 2425
- [ ] Определён список товаров, требующих сертификации
- [ ] Проверены требования карточки WB / Ozon (что не хватает)
- [ ] План получения недостающих документов (через какой ОС)
- [ ] Сохранён результат в `../my-project/05-legal/`
