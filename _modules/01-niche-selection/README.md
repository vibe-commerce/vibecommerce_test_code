# 01 — Выбор ниши

Last Updated: 2026-05-29

## Главный вопрос

«На чём зарабатывать?» — выбор ниши/категории для запуска селлерства
на маркетплейсах.

## Методика (FREE: 3 фазы)

### Фаза 1 — Лонг-лист гипотез (1-2 дня)
- Собрать 20-50 кандидатных ниш через MPStats / Google Trends / личный опыт
- Шаблон: `niche-hypotheses-template.md` *(TBD)*

### Фаза 2 — Скоринг по 5 критериям (3-5 дней)
- Объём рынка (MPStats: GMV категории)
- Рост (динамика год-к-году)
- Конкуренция (CR1 / CR3 / CR5 — доля топ-1/3/5)
- Маржинальность (приблизительно: цена / себестоимость)
- Барьеры входа (сертификация, лицензии, OEM-зависимость)

### Фаза 3 — Финал: 1-2 ниши (1-2 дня)
- Сводный балл → ниша-победитель
- Проверка на % выкупа (см. [`Сводка - процент выкупа по нишам.csv`](Сводка%20-%20процент%20выкупа%20по%20нишам.csv))
- Решение: вход / отказ / параллельный тест

## Скрипты

- `add_buyback_rate.py` — методика обогащения CSV столбцом % выкупа.
  ⚠️ Это **методика расчёта** — для использования нужен полный справочник
  выкупа (в FREE — sliced top 20-30, полный 100+ в VIP).
- `slice_buyback_top.py` — генератор FREE-среза справочника выкупа (top-N ниш
  из полной выгрузки). Запуск: `python3 slice_buyback_top.py --top 30 --by revenue`
  (`--by buyback` — сортировка по % выкупа).
