# 07 — Финансовая отчётность

Last Updated: 2026-05-29

## Главный вопрос

«Сколько я реально заработал и куда ушли деньги?» — P&L (Profit & Loss),
ДДС (Движение Денежных Средств) и упрощённый баланс для селлера-ИП.

## Что внутри (FREE)

### Шаблоны

- `templates/profit-loss-template.xlsx` — пустой P&L с формулами,
  адаптированный для селлера на МП (выручка по площадкам, комиссии, налоги, маржа)
- `templates/cashflow-template.xlsx` — пустой ДДС:
  поступления (продажи, кредиты) vs выбытия (закупка, реклама, налоги, ФОТ)
- `templates/balance-template.xlsx` — упрощённый баланс:
  активы (остатки, дебиторка) vs обязательства (кредиторка, налоги, кредиты)

> ⚠️ Шаблоны **без реальных цифр** — только структура и формулы.
> Студент заполняет своими данными в `my-project/06-finance/`.

### Методика

P&L строится по уровням:

```
1. Валовая выручка (по площадкам: WB / Ozon / ЯМ / DTC)
2. - Комиссии МП (по тарифам каждой площадки)
3. - Логистика МП (FBO / FBS / DBS)
4. - Эквайринг
5. = Чистая выручка
6. - COGS (себестоимость проданных товаров)
7. = Валовая прибыль
8. - Реклама (по каналам)
9. - ФОТ + взносы
10. - Прочие операционные расходы
11. = Операционная прибыль (EBITDA)
12. - Налоги (УСН 6% / 15% / ОСНО)
13. = Чистая прибыль
```

## Чек-лист «модуль закрыт»

- [ ] P&L заполнен за прошлый квартал (или месяц)
- [ ] ДДС заполнен с разбивкой по поступлениям/выбытиям
- [ ] Сравнение P&L vs ДДС → объяснение расхождения (нач/кон остатки, кредит/деб задолж)
- [ ] Прогноз P&L на следующий квартал
- [ ] Сохранён результат в `../my-project/06-finance/`
