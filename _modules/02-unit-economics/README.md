# 02 — Юнит-экономика

Last Updated: 2026-05-29

## Главный вопрос

«Сколько остаётся с одной продажи?» — расчёт чистой маржи на 1 SKU после всех
комиссий, налогов, рекламы, возвратов.

## Что внутри (FREE)

### Скрипты

- `scripts/price_elasticity.py` — базовая модель Arc elasticity для одного SKU
- `scripts/price_elasticity_analysis.py` — старая версия (для совместимости)
- `scripts/calc_unit_economics_tax.py` *(в работе #70)* — расчёт юнит-экономики
  с учётом налогов: УСН 6%, УСН 15%, ОСНО, НДС-агент
- `scripts/calc_marketplace_tax.py` *(в работе #70)* — расчёт комиссий
  маркетплейсов (WB / Ozon / ЯМ)

### Шаблоны

- `templates/unit-economy-template.xlsx` *(в работе #69)* — пустая матрица
  с формулами: цена → комиссия → налоги → реклама → чистая маржа.
  ⚠️ **Без реальных цифр** — только шаблон с синтетическим примером.

## Базовая формула (FREE)

```
Чистая_маржа = Цена_продажи
             - Себестоимость
             - Комиссия_МП (WB ~14-19% / Ozon ~7-25%)
             - Логистика_МП
             - Эквайринг (~1.5%)
             - Реклама_доля_от_оборота (ДРР)
             - Возврат_доля × Стоимость_возврата
             - Налог (УСН 6% от оборота / УСН 15% от прибыли / ОСНО)
             - Хранение_МП (per day × дни)
```
