# 04 — Воронка + JTBD

Last Updated: 2026-05-29

## Главный вопрос

«Кто и почему покупает у нас?» — JTBD-сегментация клиентов, граф работ,
оптимизация воронки конверсии на карточках товаров.

## Что внутри (FREE)

### Промпт

- [`jtbd-card-basic.md`](jtbd-card-basic.md) — **1 базовый JTBD-промпт-карточка**.
  Используется для упрощённого описания сегмента «job + контекст + критерии успеха».

### Методика (FREE)

Базовая JTBD-карточка для одного сегмента:

1. **Job:** что человек пытается сделать?
2. **Контекст:** когда/где/при каких условиях он покупает?
3. **Критерии успеха:** как он поймёт, что справился?
4. **Альтернативы:** чем заменяет твой товар сейчас?
5. **Барьеры:** что мешает выбрать твой товар?
